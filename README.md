# HTMLエディタ

共有用の HTML ファイルを、画面上の操作だけで手直しするエディタです。
読み込んだファイルはブラウザの中だけで扱い、外部には送信しません。

**対応ブラウザ: Chrome（Edge でも動く見込み）**

## 使い方

1. このページを Chrome で開く
2. 「ファイルを開く」で編集したい HTML を選ぶ（画面にドラッグ＆ドロップでもよい）
3. 直す
4. 「保存 ▾」から「元のファイルを上書き」か「別名で保存」を選ぶ

### 「資料」タブ（編集モード）

| やりたいこと | 操作 |
|---|---|
| 選ぶ | クリック。マウスを乗せると点線の枠、外側のまとまりは薄い枠で表示される |
| 文言を直す | ダブルクリック（または選んで Enter）。Enter で確定、Esc で取り消し、Shift+Enter で改行 |
| 下に文言を足す | 選んで「＋ 下にテキスト追加」 |
| 色を変える | 選んで右パネルの「文字の色」「背景の色」。資料でよく使われている色が先に並ぶ。「色を外す」で元に戻る |
| 消す | 選んで「🗑 削除」または Delete キー |
| まとまりごと選ぶ | 「⬆ ひとつ外側を選択」 |
| 表の行・列 | セルを選ぶと「＋ 下に行」「＋ 右に列」「行を削除」「列を削除」が出る。結合セルのある表は文言修正のみ |
| 1つ戻す | 「↩ 1つ戻す」または ⌘Z（Ctrl+Z） |

### 「資料」タブ（操作モード）

上の「👆 操作」に切り替えると、資料をふだんどおり操作できます（タブの切り替え、開閉、絞り込みボタンなど）。
開いた状態のまま「✎ 編集」に戻すと、隠れていた部分の文言も直せます。開閉の状態は保存されません。

### プログラムが作っている部分（カード・グラフ・一覧など）

資料のプログラムがデータから組み立てている部分は、画面の文字を直接は直せません。代わりに次の2つで元のデータを直します。

- **カードなどをクリック** → 右パネルに、その1件分の入力欄が出る。入れ子の一覧は下に並び、追加・削除できる
- **「データ」タブ** → データの一覧を表で全件編集できる。「＋下に追加」「削除」で1件ずつ増減

直した内容は、その1件が使われているすべての場所にすぐ反映されます。
読み取れるデータは、`<script>` の中で行頭から `const 名前 = [ … ];` の形で書かれ、値が文字・数字・true/false・null だけのものです。

## 保存について

- 元のファイルの書き方はそのままで、変えた箇所だけを書き換えます
- 上書き保存は「ファイルを開く」またはドラッグ＆ドロップで開いたときに使えます
- 最初の上書きの前に、編集前の内容を「ダウンロード」フォルダへ自動で残します（例: `資料名_backup_20261002-1530.html`）
- 編集履歴は画面を閉じると消えます

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `src/editor.css` | 画面 |
| `src/html-source.js` | HTML を読み取り、要素の位置を記録して差分で書き換える |
| `src/data-source.js` | `<script>` 内のデータを見つけて読み書きする |
| `src/app.js` | 操作の本体 |
| `build.js` | 1ファイル版 `dist/html-editor.html` を作る（`node build.js`） |
| `dist/html-editor.html` | 1ファイル版。ダウンロードして手元で開くこともできる |
